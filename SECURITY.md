
## Supported versions

Security reports for the current default branch and latest published release are in scope. Older versions may be affected and are not guaranteed to receive fixes.

## Reporting a vulnerability

Do not publish vulnerability details, secrets, proof-of-concept code, or exploit instructions in a public issue, discussion, or pull request. If GitHub shows **Report a vulnerability** in this repository's Security tab, use that private reporting form. If private reporting is unavailable, contact maintainers privately using a contact method listed on the repository owner's GitHub profile. If no private contact is available, open an issue requesting a private disclosure channel and include no vulnerability details.

## Response and disclosure

Reports are reviewed on a best-effort basis; no response or fix-time guarantee is provided. Coordinate public disclosure with the maintainers so users have a reasonable opportunity to receive a fix.
